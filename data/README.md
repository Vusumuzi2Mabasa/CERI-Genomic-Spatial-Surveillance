# Data sources and scope

This repository contains selected inputs used to reproduce joint analytical work by Vusumuzi Mabasa and Sibusiso Mahlangu during CERI training. Permission to share the supplied CERI training datasets publicly was confirmed by Vusumuzi Mabasa on 16 November 2026. That permission does not replace third-party licenses or imply CERI endorsement.

| Files | Provenance and type | Terms and acknowledgement |
|---|---|---|
| `combined_tidy_vcf.csv` | Public variant-call example linked in the original practical; three sequencing samples | [Data Carpentry genomics R materials](https://github.com/datacarpentry/genomics-r-intro); [CC BY 4.0 for instructional material and MIT for example software](https://github.com/datacarpentry/genomics-r-intro/blob/main/LICENSE.md). Retain upstream attribution. |
| `Shigella_tree.txt`, `sample_data_Shigella_tree.csv` | Published Shigella example; downloaded snapshots are byte-identical to the supplied files | [Epidemiologist R Handbook data](https://www.epirhandbook.com/en/new_pages/data_used.html), Belgian NRC for Salmonella and Shigella, the ECDC EUPHEM project and [Fischer et al.](https://doi.org/10.1093/jac/dkab377). The [tree](https://appliedepi.github.io/appliedepidata/reference/Shigella_tree.html) and [metadata](https://appliedepi.github.io/appliedepidata/reference/sample_data_Shigella_tree.html) are identified as **CC BY-NC-SA 4.0**. |
| `linelist_cleaned.rds` | **Fictional** Ebola outbreak; 5,888 rows and 30 columns. | `covid_incidence.csv` | Historical handbook mapping input; byte-identical to the supplied file. Its upstream description calls the example fictional. The file includes a global aggregate and territory names not all represented in the coarse map layer. |
| `training_timetree.nexus`, `training_tree_metadata.csv` | Supplied CERI training tree and metadata recovered from the original tree-visualisation folder. Existing topology; 256 tips, 275 metadata records | Shared with permission as confirmed above. | `local_sequencing_data.xlsx`, `Africa_sequencing_data.xlsx` | Supplied CERI sequencing-location and submission-link workbooks; 103 and 125 records | Shared with permission as confirmed above. The workbooks are selected training inputs, not a population census or measure of national sequencing throughput. No additional blanket license is asserted over these inputs. |
| Natural Earth boundaries | Coarse, 1:110m map data supplied through `rnaturalearthdata`; loaded locally by R | [Natural Earth public-domain map data](https://www.naturalearthdata.com/about/terms-of-use/). The R package retains its own software license. |

Upstream commit revisions and download URLs are recorded in `references/pinned_sources.json`. All included input files have SHA-256 fingerprints in `references/input_manifest.csv`. Source data are never modified in place by the analysis scripts.

The original commitment letter, unrelated agriculture notebook, redundant notebooks, zero-byte CSV exports, historical compiled dashboard and original notebooks containing credentials are not included. No GISAID isolate spreadsheet is bundled. The new dashboard is regenerated from the published fictional Ebola line list.

Missing resistance-gene annotations are labelled as unrecorded rather than interpreted as confirmed absence. The supplied tree metadata contain 19 records not represented in the tree. The fictional line list contains missing dates/outcomes and infector references absent from the cleaned file; those limitations remain visible in the exported audits.
